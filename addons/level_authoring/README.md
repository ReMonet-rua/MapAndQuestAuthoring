# Map & Quest Authoring

地图与任务编辑器套件，版本 **0.3.1**。包含两个可独立启用/停用的 Godot 插件：**Map Editor** 与 **Quest Editor**。已在 Godot **4.7.2** 验证；其他编辑器版本尚未验证。

## 独立插件

- **Map Editor**：`addons/level_authoring/plugin.cfg`。提供地图素材、2D 画布操作、地图连接图、传送引用管理和地图试玩前检查。
- **Quest Editor**：`addons/quest_authoring/plugin.cfg`。提供节点式任务编辑、条件双分支、对话资源引用与任务流程检查。

在 **Project > Project Settings > Plugins** 中可分别启用或停用这两个插件。发行包需同时保留 `addons/level_authoring` 与 `addons/quest_authoring`：Quest Editor 使用前者中的共享任务资源和工具代码，但不要求 Map Editor 插件处于启用状态。

Map Editor 默认扫描 `scenes/entities`、`scenes/actors`，并在 `scenes/maps` 创建地图；保存新任务或对话时会自动创建 `data/quests` 或 `data/dialogues`。传送点和检查点的跨地图运行需要可选 Autoload：将 `res://addons/level_authoring/runtime/level_authoring_world_manager.gd` 以名称 `LevelWorldManager` 加入 **Project > Project Settings > Globals > Autoload**。不使用跨地图切换时可以跳过。

发行包不包含示例游戏、地图或宿主项目设置。运行时地图、任务和对话资源会保存在安装插件的项目中。

任务编辑器负责流程创作和静态检查；任务条件、动作和对话分支尚未由通用运行时自动执行。素材库以占位场景为主，游戏特定的战斗、移动和存档系统需要由宿主项目接入。

## 当前能力

- 创建带标准图层结构的新地图
- 扫描 `scenes/entities` 和 `scenes/actors` 中的 `.tscn` 素材
- 按素材类型分类筛选，并支持按名称或路径搜索
- 在编辑器 Dock 中选择素材
- 在 2D 视图连续拖动放置素材，并按地图网格吸附
- 用选择工具框选、多选；点击素材后可继续使用 Godot 原生手柄移动
- 复制、粘贴、删除与擦除素材；粘贴时自动生成新的对象 ID
- 一整次放置或擦除笔划作为一个撤销/重做步骤
- 在独立的“地图连接图”底部面板查看跨地图传送、起点可达性、孤立地图与单向出口
- 从地图连接图直接打开地图，或定位并选中具体传送点
- 在“引用”页从地图和出生点列表设置选中传送点的目标，支持撤销/重做
- 为 NPC 创建或打开外部 CSV 对话文件
- 提供基础 CSV 对话资源解析器
- 提供独立的“任务编辑器”主页面
- 使用可拖动节点和连线编辑任务流程
- 条件节点提供“条件成立/不成立”两个分支，旧版任务连线会自动兼容
- 按节点类型配置状态条件、状态/事件动作和 CSV 对话资源引用
- 检查任务开始节点、断链、不可达节点、缺失条件/对话引用与未接分支
- 保存任务为 `data/quests/*.tres` 资源
- 根据素材类型自动放入碰撞、触发、NPC、物品、传送点等图层
- 使用 Godot Undo/Redo 撤销放置
- 自动扫描 `scenes/maps` 的地图下拉列表
- 运行选中地图或直接运行当前正在编辑的场景
- 将地图、素材和对话工具分为独立页签
- 在“校验”页检查地图 ID、地图尺寸、出生点、重复对象 ID 和跨地图传送目标
- 在地图插件中检查已保存地图、跨地图传送、未接入的触发信号和缺少解锁条件的门
- 从校验问题一键打开对应地图并选中出错节点；支持检查单张或全部地图
- 提供跨地图传送、出生点和运行时地图切换基础类
- 提供可绘制的 32×32 占位地形图集：实体块、单向平台、墙体、装饰、边缘变体和双向斜坡
- 新地图自动创建 `TileMapLayer`，并绑定占位 TileSet，可直接使用 Godot 瓦片绘制工具
- 地图根节点可配置尺寸、网格和四边阻挡边界；运行时自动生成边界碰撞
- 提供可点击放置的单向平台、出生点和触发区域占位素材
- 触发区域支持进入事件信号与单次触发
- 提供斜坡、边缘和墙体等八种可绘制地形瓦片
- 提供能力门、钥匙门和可破坏墙；障碍条件可用 ID 配置并由运行时调用解锁
- 提供尖刺危险区和可设置移动距离、速度、停顿的移动平台
- 提供可按交互键激活的开关，可链接到门；压力板支持进入/离开状态
- 提供可选自动保存的检查点、返回当前或上次检查点的基础接口
- 提供世界、任务和对话资源的第一版数据类型
- 补充秘密通道、秘密入口/稍后返回地图标记、能力拾取物和通用收集物
- 补充敌人巡逻路线、敌人出生点、遭遇波次区域和 Boss 场地占位件
- 补充商人、能力导师、地图商人和任务公告板等 NPC 服务点
- 补充抓钩点、弹跳点、可推动方块、水流区和风道等环境谜题素材
- 补充地图终端、恢复点、奖励宝箱和追猎封锁区素材，并提供对应交互/遭遇信号接口
- 增加全素材展示试玩关卡，覆盖素材库现有实体、占位瓦片、基础地形与移动路线

## 使用方式

1. 在 Project Settings > Plugins 中按需启用 `Map Editor` 和 `Quest Editor`；两者可以单独开关。
2. 打开或新建地图场景。
3. 在“关卡搭建”Dock 的“素材”页签中选择素材。
4. 在“工具”下拉框选择“放置”，可开关“吸附”，然后在 2D 视图拖动连续铺放素材；按住鼠标的一笔可一次撤销。
5. 选择“选择”，在空白处拖动框选；按住 Shift 可追加选择。点击素材可进入 Godot 原生选择，之后可直接拖动其移动手柄。
6. 选择素材后按 Ctrl+C / Ctrl+V 复制粘贴，按 Delete 删除；选择“擦除”可在视图中拖动删除素材。复制、删除和擦除都支持撤销。
7. 在“地图”页签中选择地图，使用“打开”或“运行选中”；编辑任意已保存场景时，可以点击“运行当前场景”。
8. 在“对话”页签中选中 NPC，点击“编辑选中 NPC 对话”。
9. 使用 Excel、LibreOffice 或文本编辑器修改 CSV；保存后回到 Godot 刷新资源。
10. 启用 `Quest Editor` 后，在右侧“任务编辑器”Dock 中选择或新建任务，添加节点并拖动端口连线；条件节点分别从“条件成立”和“条件不成立”端口连出。
11. 选中节点后按类型填写条件、动作或对话资源 ID，点击“应用节点属性”；用“检查流程”查看断链、不可达节点和缺失配置。
12. 启用 `Map Editor` 后，在“校验”页检查单张或全部地图，也可用“地图试玩前检查”检查传送、触发器与门配置。任务流程由 `Quest Editor` 单独检查。校验读取磁盘中已保存的资源，修改后请先保存再检查。
13. 点击底部的“地图连接图”面板，选择可达性起点；从图中的地图卡片打开场景，或在传送点行点击“定位”。
14. 选中传送点后打开“引用”页，从列表选择目标地图和出生点，再点击“应用传送目标”。

## 地图编辑器迭代计划

1. **画布操作效率（已实现）**：连续拖动放置、网格吸附、框选/多选、原生手柄移动、复制粘贴、擦除与撤销。
2. **地图连接图（已实现）**：按地图与传送点生成只读拓扑，标出从所选起点不可达的地图、孤立地图和单向出口，并支持打开地图及定位传送点。
3. **属性与引用管理（传送目标第一版已实现）**：选中传送点后从地图和出生点列表设置目标并支持撤销；后续扩展到任务条件、门和对话资源。
4. **低代码任务与剧情连线（编辑器第一版已实现）**：可配置条件、动作、对话引用和条件双分支；后续扩展共享状态目录，并把 NPC 对话分支、触发区和门接入同一事件流。当前编辑器负责创作与结构检查，尚未由通用运行时执行这些动作。
5. **试玩前诊断（第一版已实现）**：Map Editor 检查已保存地图中的未连接传送点、触发信号和障碍条件；Quest Editor 分别检查任务断链、不可达节点及缺失引用。后续可增加试玩运行日志和实际触发结果检查。

后续优先级以“先看清地图之间如何连通，再集中管理对象引用，然后完善剧情逻辑和试玩诊断”为序；每阶段都保留场景可独立运行、可撤销和可回归验证的验收标准。

## 占位地形瓦片

地图场景中的 `TileLayer` 使用 32×32 瓦片，图集依次包含实体平台、单向平台、实体墙、无碰撞装饰、边缘变体、上坡、下坡和石质变体。新建地图会自动绑定该图集；现有地图也已预绑定，可在 TileMapLayer 的绘制面板中选择瓦片并涂画。

地图根节点 `LevelAuthoringMap` 提供地图尺寸、网格尺寸、四边阻挡开关和边界厚度设置。触发器放在 `TriggersLayer`，进入时发出 `triggered` 信号；具体任务或剧情响应可在后续接入。

新增素材都使用占位形状。能力门/钥匙门填写 `required_condition_id` 后，可由能力或任务逻辑调用 `unlock_with(id)`；破坏墙可调用 `apply_hit(damage_type)`；秘密通道可由探索逻辑调用 `reveal()`，揭示后会开放通行。开关填写相对 `linked_target_path` 可控制具备 `set_open()` 的门。检查点默认只记录本次运行位置；勾选 `save_automatically` 后会调用现有自动存档，并可通过 `LevelWorldManager.respawn_at_checkpoint()` 返回检查点。危险区、能力/收集物、遭遇区和 NPC 服务点都提供信号或调用接口，供战斗、背包、任务和对话系统接入。

地图终端与恢复点在玩家进入交互范围后按 `E` 发出 `station_activated`；奖励宝箱按 `E` 发出 `chest_opened`，供地图、存档、背包系统接入。追猎封锁区沿用遭遇区的开始/完成信号，可关联阻挡门。它们目前是可配置的集成接口，不会自行解锁地图、恢复生命或发放奖励。

敌人出生点可填写敌人场景并由 `spawn_enemy()` 实例化；巡逻路线以可编辑的 `route_points` 保存路径数据，但尚未自动驱动敌人 AI。遭遇区可配置波次 ID 和关联门路径，调用 `complete()` 后会开放关联门；波次生成与 Boss 战斗仍由后续战斗系统处理。NPC 服务点通过 `request_service()` 发出服务请求，可配置 `condition_id` 并由调用者传入已满足的条件 ID。抓钩点、弹跳点、水流区和风道会发出激活/进入/离开信号并提供方向向量，目前不会直接改变玩家运动。可推动方块是基础 `RigidBody2D` 占位件；真实物理手感还需结合玩家碰撞层和移动控制调试。

秘密入口/稍后返回标记默认只在编辑器可见；`show_in_game` 可用于临时显示。标记本身不会自动发现地图区域，需要由地图探索或能力系统调用 `reveal()`。任务条件、分支对话、NPC 交互界面、战斗 AI 和玩家运动仍需后续接入相应游戏系统。
