# Changelog

## 0.3.1 — 2026-10-29

- Updated publisher and copyright attribution to ReMonet.
- Prepared the package metadata for Godot Asset Store distribution.

## 0.3.0 — 2026-10-29

- Renamed the combined product to Map & Quest Authoring.
- Split Map Editor and Quest Editor into separately switchable Godot plugins.
- Kept quest data models and shared helpers bundled with the map authoring runtime while allowing Quest Editor to run with Map Editor disabled.
- Separated map playtest checks from quest workflow checks.
- Added independent plugin installation and dependency documentation.

## 0.2.0 — 2026-10-29

- Added continuous canvas placement, grid snapping, marquee selection, copy/paste, erasing, and stroke-level undo.
- Added a cross-map portal graph and an inspector for choosing target maps and spawn points.
- Added typed quest nodes, condition branches, legacy quest-link compatibility, and flow diagnostics.
- Added a map preflight report for portals, triggers, and barriers.
- Made map, quest, and dialogue output folders self-creating on first use.
- Added standalone installation notes and the MIT license.
